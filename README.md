# CodeRun - Code Snippet Run

CodeRun 是一款在手机上运行和编辑代码片段的工具，内置 600 多种编程语言。
CodeRun is a mobile tool for running and editing code snippets in 600+ programming languages.

🇨🇳 中文 · 🇬🇧 English — 页面右上角可切换语言 / use the toggle in the top-right corner to switch languages.
